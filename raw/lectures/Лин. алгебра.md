## 3. Теорема разложения определителя (n > 3)

### Минор и алгебраическое дополнение

- **Минор** MijMij​ — определитель матрицы, полученной вычёркиванием ii-й строки и jj-го столбца.
    
- **Алгебраическое дополнение:** Aij=(−1)i+jMijAij​=(−1)i+jMij​
    

### Теорема разложения (Лапласа)

Определитель равен сумме произведений элементов любой строки (или столбца) на их алгебраические дополнения:

det⁡A=∑j=1naijAij(разложение по i-й строке)detA=∑j=1n​aij​Aij​(разложение по i-й строке)

det⁡A=∑i=1naijAij(разложение по j-му столбцу)detA=∑i=1n​aij​Aij​(разложение по j-му столбцу)

**Следствие (теорема аннулирования):**

∑j=1naijAkj=0при i≠k∑j=1n​aij​Akj​=0при i=k

### Метод понижения порядка

1. Выбираем строку/столбец с максимумом нулей.
    
2. Раскладываем по этой строке/столбцу.
    
3. Получаем определители меньшего порядка.
    

**Пример:** Для det⁡AdetA 4-го порядка разложение по ii-й строке даёт 4 определителя 3-го порядка.

### Свойства определителей

1. det⁡A=det⁡ATdetA=detAT
    
2. При перестановке двух строк det⁡det меняет знак
    
3. det⁡(λA)=λndet⁡Adet(λA)=λndetA
    
4. det⁡(AB)=det⁡A⋅det⁡Bdet(AB)=detA⋅detB
    
5. Если строка — линейная комбинация других, det⁡=0det=0
    
6. Прибавление к строке другой строки, умноженной на число, не меняет det⁡det

## 4. Линейная функция матриц

Функция f:Mn→Rf:Mn​→R называется **линейной**, если:

1. f(A+B)=f(A)+f(B)f(A+B)=f(A)+f(B) — аддитивность
    
2. f(λA)=λf(A)f(λA)=λf(A) — однородность
