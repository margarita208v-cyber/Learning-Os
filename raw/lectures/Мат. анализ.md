# Лекция по математическому анализу: Пределы и производные

## Часть I. Пределы

### 1.1. Интуитивное понятие предела

Рассмотрим функцию $f(x) = \frac{x^2 - 1}{x - 1}$. В точке $x = 1$ функция не определена (деление на ноль), но нас интересует поведение функции **вблизи** этой точки.

Подставляя значения $x$, близкие к 1:
- $x = 0{,}9 \Rightarrow f(x) = 1{,}9$
- $x = 0{,}99 \Rightarrow f(x) = 1{,}99$
- $x = 1{,}01 \Rightarrow f(x) = 2{,}01$
- $x = 1{,}1 \Rightarrow f(x) = 2{,}1$

Видно, что $f(x) \to 2$ при $x \to 1$. Это и есть **предел функции**.

### 1.2. Строгое определение (Коши)

**Определение.** Число $A$ называется **пределом функции** $f(x)$ в точке $a$, если для любого $\varepsilon > 0$ существует такое $\delta > 0$, что для всех $x$, удовлетворяющих условию $0 < |x - a| < \delta$, выполняется неравенство $|f(x) - A| < \varepsilon$.

Обозначение: $\lim\limits_{x \to a} f(x) = A$.

**Смысл:** какую бы узкую полосу $(A - \varepsilon, A + \varepsilon)$ мы ни взяли, найдётся такая окрестность точки $a$, что все значения функции в ней (кроме, быть может, самой точки $a$) попадут в эту полосу.

### 1.3. Свойства пределов

Если $\lim\limits_{x \to a} f(x) = A$ и $\lim\limits_{x \to a} g(x) = B$, то:

1. $\lim (f(x) \pm g(x)) = A \pm B$
2. $\lim (f(x) \cdot g(x)) = A \cdot B$
3. $\lim \dfrac{f(x)}{g(x)} = \dfrac{A}{B}$, если $B \neq 0$
4. $\lim (c \cdot f(x)) = c \cdot A$

### 1.4. Замечательные пределы

**Первый замечательный предел:**
$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

**Второй замечательный предел:**
$$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e \approx 2{,}71828\ldots$$

Число $e$ — основание натурального логарифма.

### 1.5. Непрерывность

Функция $f(x)$ **непрерывна** в точке $a$, если:
$$\lim_{x \to a} f(x) = f(a)$$

Это означает: предел существует, функция определена в точке, и они совпадают. График непрерывной функции можно нарисовать, не отрывая карандаша от бумаги.

## Часть II. Производная

### 2.1. Задача о касательной и мгновенной скорости

**Геометрическая задача.** Как найти наклон касательной к графику функции в точке?

**Физическая задача.** Как найти мгновенную скорость тела, движущегося неравномерно?

Обе задачи приводят к одному понятию — **производной**.

### 2.2. Определение производной

**Определение.** Производной функции $f(x)$ в точке $x$ называется предел отношения приращения функции к приращению аргумента, когда приращение аргумента стремится к нулю:

$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

Обозначения: $f'(x)$, $y'$, $\dfrac{df}{dx}$, $\dfrac{dy}{dx}$.

**Геометрический смысл:** $f'(x_0)$ — угловой коэффициент касательной к графику функции в точке $x_0$:
$$k = \tan \alpha = f'(x_0)$$

**Физический смысл:** если $s(t)$ — путь, то $s'(t) = v(t)$ — мгновенная скорость.

### 2.3. Пример вычисления по определению

Найдём производную $f(x) = x^2$:

$$f'(x) = \lim_{\Delta x \to 0} \frac{(x + \Delta x)^2 - x^2}{\Delta x} = \lim_{\Delta x \to 0} \frac{x^2 + 2x\Delta x + (\Delta x)^2 - x^2}{\Delta x}$$

$$= \lim_{\Delta x \to 0} \frac{2x\Delta x + (\Delta x)^2}{\Delta x} = \lim_{\Delta x \to 0} (2x + \Delta x) = 2x$$

Итак, $(x^2)' = 2x$.

### 2.4. Таблица производных основных функций

| Функция $f(x)$ | Производная $f'(x)$ |
|---|---|
| $C$ (константа) | $0$ |
| $x^n$ | $n x^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\dfrac{1}{\cos^2 x}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $\dfrac{1}{x}$ |
| $a^x$ | $a^x \ln a$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ |

### 2.5. Правила дифференцирования

Пусть $u = u(x)$, $v = v(x)$ — дифференцируемые функции. Тогда:

1. **Сумма:** $(u \pm v)' = u' \pm v'$
2. **Произведение:** $(uv)' = u'v + uv'$
3. **Частное:** $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$
4. **Сложная функция (цепное правило):** если $y = f(g(x))$, то
$$y' = f'(g(x)) \cdot g'(x)$$

**Пример:** $y = \sin(3x^2)$. Тогда $y' = \cos(3x^2) \cdot 6x = 6x\cos(3x^2)$.

### 2.6. Применения производной

**1. Уравнение касательной** к графику $y = f(x)$ в точке $x_0$:
$$y = f(x_0) + f'(x_0)(x - x_0)$$

**2. Признак монотонности:**
- Если $f'(x) > 0$ на интервале, функция **возрастает**
- Если $f'(x) < 0$ — **убывает**

**3. Экстремумы.** Точка $x_0$ — точка **максимума/минимума**, если производная меняет знак при переходе через неё:
- с $+$ на $-$ → максимум
- с $-$ на $+$ → минимум

**Необходимое условие:** $f'(x_0) = 0$ (критическая точка).

**4. Правило Лопиталя** для раскрытия неопределённостей $\frac{0}{0}$ и $\frac{\infty}{\infty}$:
$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$$

**Пример:** $\lim\limits_{x \to 0} \dfrac{\sin x}{x} = \lim\limits_{x \to 0} \dfrac{\cos x}{1} = 1$.

## Часть III. Итоги и связь понятий

| Понятие | Определение | Смысл |
|---|---|---|
| Предел | Поведение функции вблизи точки | «Куда стремится» |
| Непрерывность | $\lim f(x) = f(a)$ | Нет разрывов |
| Производная | Предел отношения приращений | Скорость изменения |

**Ключевая идея:** производная — это предел. Всё математическое анализа строится на понятии предела. Освоив пределы, вы получаете ключ к дифференциальному и интегральному исчислению.
