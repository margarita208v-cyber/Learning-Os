# Raw: неизменяемые доказательства

Сюда добавляются исходные материалы: собственные записи лекций, разрешённые преподавателем материалы, ссылки на статьи, задания, данные и медиа. После добавления файл не редактируется, не переименовывается и не перемещается: история и хэш Git фиксируют, на чём основана wiki.

Если нужно исправить транскрипт, добавьте новый файл с датой и суффиксом `-correction`, а связь запишите в `log/ingest.md`. Если материал защищён авторским правом или условиями курса, не загружайте копию в публичный GitHub: вместо этого создайте source-карточку с разрешённой ссылкой, библиографией и личной аннотацией.
