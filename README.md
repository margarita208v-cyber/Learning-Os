# Learning OS / Second Brain

Универсальный личный учебный репозиторий для всего периода обучения. Он объединяет Obsidian, Git/GitHub и LLM в систему, где доказательства, понимание и скомпилированное знание хранятся раздельно.

## Модель системы

```text
raw/ (источники, не менять) ──→ wiki/ (проверяемое, связное знание)
          │                                  │
          └────→ learning/ (моё понимание) ──┴──→ labs/ и projects/ (результаты)
                              ↑
                  LLM помогает, но не является источником истины
```

Это Karpathy-style LLM Wiki: `raw/` — неизменяемые человеческие доказательства; `wiki/` — производная база знаний, которую LLM может поддерживать только с явными ссылками на источники; `log/` — append-only журнал действий. Первичным автором и ответственным за качество остаётся студент.

## Первый день (20–30 минут)

1. Создайте репозиторий из этого шаблона через GitHub **Use this template** или скопируйте папку.
2. Откройте эту папку в Obsidian: **Open folder as vault**. Настройки уже лежат в `.obsidian/`.
3. Прочитайте [AGENTS.md](AGENTS.md) и [AI_POLICY.md](AI_POLICY.md).
4. Укажите свои данные в `README.md` ниже, затем сделайте первый коммит.
5. Положите одну лекцию или статью в `raw/`, создайте её карточку в `wiki/sources/`, и внесите запись в `log/ingest.md`.
6. После занятия создайте заметку по шаблону `templates/lecture.md`, а после самостоятельного разбора — одну заметку понятия из `templates/concept.md`.

## Карта папок

| Папка | Владелец | Назначение |
| --- | --- | --- |
| `raw/` | человек | исходные материалы и доказательства; после добавления не редактировать |
| `wiki/` | LLM + человек | скомпилированное знание с provenance и индексами |
| `learning/` | человек | конспекты, вопросы, решения, рефлексии и подготовка к экзаменам |
| `labs/`, `projects/` | человек | сдаваемые работы и проектный практикум |
| `llm/` | человек | версии промптов, запросы, сохранённые ответы, проверки |
| `log/` | человек + LLM | только добавление строк: ingest, запросы, обучение, применение ИИ |
| `templates/` | человек | шаблоны заметок для Obsidian |

## Базовый ритм

**После занятия:** сохранить материал в `raw/` → записать личный конспект в `learning/lectures/` → добавить вопросы.

**После разбора темы:** обновить сначала `wiki/index.md`, затем 1–3 связанные wiki-заметки, добавить ссылки на `wiki/sources/` и проверить факты.

**Перед сдачей:** оформить работу в `labs/` или `projects/`, задокументировать вклад LLM в `log/ai-usage.md`, не выдавать сгенерированный текст за собственную работу.

**Раз в неделю:** очистить Inbox, ответить на открытые вопросы, исправить битые ссылки, сделать коммит и push.

Полный порядок работы: [CONTRIBUTING.md](CONTRIBUTING.md). Правила LLM: [AI_POLICY.md](AI_POLICY.md).

## Навигация в Obsidian

Начинайте с [wiki/index.md](wiki/index.md). Используйте внутренние ссылки вида `[[concept-name]]`, теги только для поперечных срезов (`#status/draft`, `#review-needed`), а не вместо структуры папок. Не добавляйте в Git личные токены, пароли, закрытые материалы курса или персональные данные других людей.
