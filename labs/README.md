# Лабораторные работы

Для каждой работы создавайте папку `YYYY-term-lab-<nn>-<slug>/` с `README.md`, отчётом, кодом/данными и краткими инструкциями воспроизведения. В README укажите задание, собственный вклад, запуск, источники, ограничения и раскрытие LLM согласно правилам курса. Не коммитьте результаты, содержащие чужие персональные данные, секреты или закрытые датасеты.
