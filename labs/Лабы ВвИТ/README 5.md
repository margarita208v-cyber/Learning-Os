## Цель работы

Освоить базовые механизмы ООП в Python:
- классы и объекты, конструктор `__init__`;
- инкапсуляцию через `@property` и `@setter`;
- наследование и `super().__init__()`;
- переопределение методов (`get_info`, `__str__`, `move`);
- абстрактные классы (`ABC`, `@abstractmethod`);
- полиморфизм — единый вызов метода для объектов разных классов;
- организацию проекта в пакеты и модули.

## Что понято в результате работы

1. **Инкапсуляция** — `_speed` защищён соглашением, а `@property speed` с `@setter`
   не даёт установить отрицательную скорость (`ValueError`). Методы `accelerate`
   и `brake` работают через свойство, а не через поле напрямую.

2. **Наследование** — `Car`, `Truck`, `Motorcycle`, `ElectricCar` используют
   `super().__init__()` для общей части (brand, model, year, _speed) и добавляют
   свои атрибуты. Переопределяют `get_info()`, расширяя родительский вывод.

3. **Абстракция** — `Vehicle` наследует `ABC` и содержит `@abstractmethod move()`.
   Создать `Vehicle(...)` напрямую нельзя (`TypeError`) — это гарантирует, что
   у каждого конкретного ТС есть своя реализация движения.

4. **Полиморфизм** — в цикле `for v in vehicles: v.move()` Python по фактическому
   типу объекта вызывает нужную реализацию. Никаких `isinstance()` в коде нет.
   Именно это позволяет добавлять новые классы (`ElectricCar`) без изменения
   `Garage` и демонстрационного цикла.

5. **Организация проекта** — `__init__.py` превращает `models/` в пакет и
   реэкспортирует классы, поэтому в `main.py` достаточно одной строки импорта.
   Относительные импорты (`from .vehicle import Vehicle`) работают только при
   запуске из корня (`python main.py`), а не при прямом запуске файлов пакета.

6. **Принцип открытости/закрытости** — новый класс `ElectricCar` встроился в
   общий список и в `Garage` без единой правки существующего кода: он соблюдает
   интерфейс `Vehicle` (`brand`, `get_info`, `move`).

## Проверка ключевых сценариев

В `main.py` продемонстрировано:

- попытка создать `Vehicle` → `TypeError` (абстрактный класс);
- `accelerate(60)` → скорость 60, `brake(100)` → 0 (не уходит в минус), `stop()` → 0;
- `car.speed = -10` → `ValueError`;
- `print(car)` → сработал `__str__`;
- полиморфный цикл по `[Car, Truck, Motorcycle, ElectricCar]` — у каждого свой
  `move()` и `get_info()`;
- работа `Garage`: добавление, показ, поиск по марке, удаление;
- `ElectricCar` в общем списке — без специальных проверок типа.
