# Комплексные числа

## 1. Основы и определения
**Комплексное число** $z$ — это число вида:
$$z = a + bi$$
где $a, b \in \mathbb{R}$, а $i$ — мнимая единица, такая что $i^2 = -1$.

- $a = \text{Re}(z)$ — **действительная часть**
- $b = \text{Im}(z)$ — **мнимая часть**

**Множество $\mathbb{C}$**: $\{a + bi \mid a, b \in \mathbb{R}\}$. Если $b = 0$, число является действительным ($\mathbb{R} \subset \mathbb{C}$).

**Степени мнимой единицы**:
$i^1 = i, \quad i^2 = -1, \quad i^3 = -i, \quad i^4 = 1$. (Цикл повторяется каждые 4 степени).

---

## 2. Алгебраические операции
Пусть $z_1 = a_1 + b_1 i$ и $z_2 = a_2 + b_2 i$.

- **Сложение и вычитание**:
  $$z_1 \pm z_2 = (a_1 \pm a_2) + (b_1 \pm b_2)i$$
- **Умножение**:
  $$z_1 \cdot z_2 = (a_1 a_2 - b_1 b_2) + (a_1 b_2 + a_2 b_1)i$$
- **Сопряжение**: $\bar{z} = a - bi$. Свойство: $z \cdot \bar{z} = a^2 + b^2 = |z|^2$.
- **Деление**:
  $$\frac{z_1}{z_2} = \frac{z_1 \bar{z}_2}{|z_2|^2}$$

- **Модуль**: $|z| = \sqrt{a^2 + b^2}$. Выполняется неравенство треугольника: $|z_1 + z_2| \le |z_1| + |z_2|$.

---

## 3. Геометрия и тригонометрия
Комплексное число изображается точкой $(a, b)$ на комплексной плоскости.

### Тригонометрическая форма
$$z = r(\cos \varphi + i \sin \varphi)$$
где $r = |z| = \sqrt{a^2 + b^2}$ (модуль), $\varphi = \arg z$ (аргумент).

**Вычисление аргумента $\varphi$**:
- I четв: $\varphi = \arctan \frac{b}{a}$
- II четв: $\varphi = \pi + \arctan \frac{b}{a}$
- III четв: $\varphi = \pi + \arctan \frac{b}{a}$
- IV четв: $\varphi = 2\pi + \arctan \frac{b}{a}$

### Формула Муавра и корни
- **Степень**: $z^n = r^n (\cos(n\varphi) + i \sin(n\varphi))$
- **Корень**: $z^{1/n} = \sqrt[n]{r} \left( \cos \frac{\varphi + 2\pi k}{n} + i \sin \frac{\varphi + 2\pi k}{n} \right), k = 0, 1, \dots, n-1$.

---

## 4. Показательная форма и формула Эйлера
**Формула Эйлера**: $e^{i\varphi} = \cos \varphi + i \sin \varphi$.
**Показательная форма**:
$$z = r e^{i\varphi}$$

**Свойства**:
- $z_1 z_2 = r_1 r_2 e^{i(\varphi_1 + \varphi_2)}$
- $\frac{z_1}{z_2} = \frac{r_1}{r_2} e^{i(\varphi_1 - \varphi_2)}$
- $\cos \varphi = \frac{e^{i\varphi} + e^{-i\varphi}}{2}, \quad \sin \varphi = \frac{e^{i\varphi} - e^{-i\varphi}}{2i}$
