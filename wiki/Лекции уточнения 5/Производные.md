# Производная функции

## 1. Определение и смысл
**Производная** — это предел отношения приращения функции к приращению аргумента:
$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

- **Геометрический смысл**: $f'(x_0) = \tan \alpha$, где $\alpha$ — угол наклона касательной.
- **Физический смысл**: Мгновенная скорость изменения процесса.

## 2. Техника дифференцирования
### Основные правила
- $(u \pm v)' = u' \pm v'$
- $(uv)' = u'v + uv'$
- $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$
- **Сложная функция**: $(f(g(x)))' = f'(g(x)) \cdot g'(x)$

### Таблица основных производных
- $(x^n)' = n x^{n-1}$
- $(\sin x)' = \cos x$
- $(\cos x)' = -\sin x$
- $(e^x)' = e^x$
- $(\ln x)' = \frac{1}{x}$

## 3. Применение производной
- **Уравнение касательной**: $y = f(x_0) + f'(x_0)(x - x_0)$.
- **Монотонность**: $f'(x) > 0 \implies$ возрастание; $f'(x) < 0 \implies$ убывание.
- **Экстремумы**: Точки, где $f'(x) = 0$ и производная меняет знак.
- **Правило Лопиталя**: $\lim \frac{f(x)}{g(x)} = \lim \frac{f'(x)}{g'(x)}$ (для неопределенностей $\frac{0}{0}, \frac{\infty}{\infty}$).
