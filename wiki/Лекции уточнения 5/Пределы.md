# Пределы функций: глубокий разбор

## 1. Понятие предела и интуиция
Предел $\lim_{x \to a} f(x) = A$ означает, что мы можем сделать значение функции сколь угодно близким к $A$, если возьмем $x$ достаточно близко к $a$.

**Пример с «дыркой» в графике**:
Рассмотрим $f(x) = \frac{x^2 - 9}{x - 3}$. В точке $x=3$ функция не определена ($0/0$).
Однако, если мы сократим выражение: $\frac{(x-3)(x+3)}{x-3} = x+3$.
Тогда $\lim_{x \to 3} (x+3) = 6$. 
*Геометрически*: график — это прямая с маленькой «дыркой» в точке $(3, 6)$.

### Строгое определение ($\varepsilon-\delta$):
$\forall \varepsilon > 0 \exists \delta > 0 : 0 < |x - a| < \delta \implies |f(x) - A| < \varepsilon$.
*Смысл*: $\varepsilon$ — это допустимая ошибка по вертикали (ось $Y$), $\delta$ — радиус окрестности по горизонтали (ось $X$).

## 2. Раскрытие неопределенностей вида $\frac{0}{0}$
Когда мы получаем $\frac{0}{0}$, функция «скрывает» свое истинное значение.

**Методы решения (Примеры)**:
1. **Разложение на множители**:
   $\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x-2)(x+2)}{x-2} = \lim_{x \to 2} (x+2) = 4$.
2. **Умножение на сопряженное**:
   $\lim_{x \to 0} \frac{\sqrt{x+1} - 1}{x} = \lim_{x \to 0} \frac{(\sqrt{x+1} - 1)(\sqrt{x+1} + 1)}{x(\sqrt{x+1} + 1)} = \lim_{x \to 0} \frac{x+1-1}{x(\sqrt{x+1} + 1)} = \frac{1}{2}$.
3. **Правило Лопиталя**:
   Если имеем $\frac{0}{0}$ или $\frac{\infty}{\infty}$, берем производные отдельно:
   $\lim_{x \to 0} \frac{\sin x}{x} \xrightarrow{\text{L}} \lim_{x \to 0} \frac{(\sin x)'}{(x)'} = \lim_{x \to 0} \frac{\cos x}{1} = 1$.

## 3. Замечательные пределы (ZП)
**Первый (Тригонометрический)**: $\lim_{x \to 0} \frac{\sin x}{x} = 1$.
- *Важно*: аргумент должен быть в радианах.
- *Следствие*: $\lim_{x \to 0} \frac{\tan x}{x} = 1$.

**Второй (Экспоненциальный)**: $\lim_{x \to \infty} (1 + \frac{1}{x})^x = e$.
- Используется для вычисления пределов с неопределенностью $1^\infty$.

---

## 4. Эквивалентные бесконечно малые (ЭБМ)
При $x \to 0$ сложные функции можно заменить простыми $\sim$. Это «чит-код» для быстрого решения пределов.

**Таблица замен**:
- $\sin x \sim x$
- $\tan x \sim x$
- $\ln(1+x) \sim x$
- $e^x - 1 \sim x$
- $1 - \cos x \sim \frac{x^2}{2}$

**Пример использования**:
$\lim_{x \to 0} \frac{\sin 5x}{\ln(1+3x)} = \lim_{x \to 0} \frac{5x}{3x} = \frac{5}{3}$.
(Мы просто заменили $\sin 5x$ на $5x$ и $\ln(1+3x)$ на $3x$).
