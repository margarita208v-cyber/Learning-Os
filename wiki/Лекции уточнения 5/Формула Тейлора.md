# Конспект: Формула Тейлора

## 1. Формула Тейлора для многочлена

### 1.1 Постановка

Пусть $P(x)$ — многочлен степени не выше $n$:
$$P(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n.$$

**Теорема.** Любой многочлен степени $\le n$ можно единственным образом представить в виде разложения по степеням $(x - x_0)$:
$$P(x) = c_0 + c_1(x-x_0) + c_2(x-x_0)^2 + \dots + c_n(x-x_0)^n.$$

### 1.2 Нахождение коэффициентов

Дифференцируем $k$ раз и подставляем $x = x_0$:
$$P^{(k)}(x_0) = k!\, c_k \quad\Rightarrow\quad c_k = \frac{P^{(k)}(x_0)}{k!}.$$

**Итог — формула Тейлора для многочлена:**
$$\boxed{P(x) = \sum_{k=0}^{n} \frac{P^{(k)}(x_0)}{k!}(x-x_0)^k}$$

**Ключевой момент:** для многочлена степени $\le n$ это **точное равенство** — остаточного члена нет (он тождественно равен нулю). Это «идеальный» случай формулы Тейлора.

### 1.3 Следствие (единственность)

Если два многочлена степени $\le n$ совпадают в точке $x_0$ вместе со всеми производными до порядка $n$, то они тождественно равны. Отсюда — единственность многочлена Тейлора.

## 2. Формула Тейлора для $(n+1)$-кратно дифференцируемой функции

### 2.1 Условия

Пусть $f$ определена в окрестности $x_0$ и имеет в ней производные до порядка $n$ включительно, а также производную порядка $n+1$ (в окрестности или в точке — зависит от формы остатка).

### 2.2 Многочлен Тейлора

$$T_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k$$

— единственный многочлен степени $\le n$, у которого
$$T_n^{(k)}(x_0) = f^{(k)}(x_0), \quad k = 0,1,\dots,n.$$

### 2.3 Сама формула

$$\boxed{f(x) = T_n(x) + R_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + R_n(x)}$$

где $R_n(x)$ — **остаточный член** (разность между функцией и многочленом Тейлора).

При $x_0 = 0$ — **формула Маклорена**:
$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(0)}{k!}x^k + R_n(x).$$

### 2.4 Смысл

- Многочлен $T_n$ — «главная часть» функции вблизи $x_0$.
- $R_n$ — погрешность приближения; её поведение определяет качество формулы.
- Для многочлена степени $\le n$: $R_n \equiv 0$ — согласуется с п. 1.

## 3. Остаточный член в разных формах

Все формы описывают **одну и ту же величину** $R_n(x)$, но различаются требованиями к гладкости и способом применения.

### 3.1 Форма Пеано (локальная)

**Условие:** $f$ имеет $n$ производных в точке $x_0$ (достаточно $f^{(n)}(x_0)$).

$$R_n(x) = o\big((x-x_0)^n\big), \quad x \to x_0.$$

**Смысл:** остаток убывает быстрее $(x-x_0)^n$. Характеризует поведение **только вблизи** $x_0$, численной оценки не даёт.

**Применение:** вычисление пределов, раскрытие неопределённостей, локальный анализ.

### 3.2 Форма Лагранжа (глобальная)

**Условие:** $f$ имеет $n+1$ производную в окрестности.

$$\boxed{R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}}, \quad \xi \text{ между } x_0 \text{ и } x.$$

**Смысл:** даёт **явную оценку** погрешности через максимум $|f^{(n+1)}|$ на промежутке:
$$|R_n(x)| \le \frac{M_{n+1}}{(n+1)!}|x-x_0|^{n+1}.$$

**Применение:** приближённые вычисления с гарантированной точностью, доказательство неравенств.

### 3.3 Форма Коши

**Условие:** те же, что для Лагранжа.

$$R_n(x) = \frac{f^{(n+1)}(\xi)}{n!}(x-\xi)^n(x-x_0), \quad \xi \text{ между } x_0 \text{ и } x.$$

**Смысл:** альтернативное представление; удобна при исследовании сходимости рядов в граничных точках и в некоторых специальных оценках.

### 3.4 Интегральная форма

**Условие:** $f^{(n+1)}$ непрерывна на промежутке.

$$\boxed{R_n(x) = \frac{1}{n!}\int_{x_0}^{x} f^{(n+1)}(t)\,(x-t)^n\,dt}$$

**Смысл:** получается из формулы Ньютона–Лейбница; наиболее «конструктивная» форма. Из неё, применяя теорему о среднем, выводятся формы Лагранжа и Коши.

### 3.5 Сводная таблица

| Форма | Требования | Вид $R_n(x)$ | Основное применение |
|---|---|---|---|
| Пеано | $f^{(n)}(x_0)$ | $o((x-x_0)^n)$ | пределы, локальный анализ |
| Лагранж | $f^{(n+1)}$ в окрестности | $\dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$ | оценки погрешности |
| Коши | $f^{(n+1)}$ в окрестности | $\dfrac{f^{(n+1)}(\xi)}{n!}(x-\xi)^n(x-x_0)$ | сходимость рядов, спец. оценки |
| Интегральная | $f^{(n+1)}$ непрерывна | $\dfrac{1}{n!}\int_{x_0}^{x} f^{(n+1)}(t)(x-t)^n dt$ | доказательства, вывод других форм |

## 4. Связь с рядом Тейлора

Если $f$ бесконечно дифференцируема и $R_n(x) \to 0$ при $n \to \infty$, то
$$f(x) = \sum_{k=0}^{\infty} \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k$$
— **ряд Тейлора** сходится к $f(x)$.

**Важно:** гладкости **недостаточно**! Пример: $f(x) = e^{-1/x^2}$ ($x \neq 0$), $f(0)=0$ — все производные в нуле равны нулю, ряд Тейлора тождественно нулевой, но $f \not\equiv 0$. Такая функция не аналитична в нуле.

## 5. Стандартные разложения (Маклорен)

$$e^x = 1 + x + \frac{x^2}{2!} + \dots + \frac{x^n}{n!} + R_n;$$

$$\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots + (-1)^m\frac{x^{2m+1}}{(2m+1)!} + R_{2m+1};$$

$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots + (-1)^m\frac{x^{2m}}{(2m)!} + R_{2m};$$

$$\ln(1+x) = x - \frac{x^2}{2} + \frac{x^3}{3} - \dots + (-1)^{n-1}\frac{x^n}{n} + R_n, \quad |x|<1;$$

$$(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \dots + \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}x^n + R_n.$$

---

## 6. Главные выводы конспекта

1. **Для многочлена** формула Тейлора — точное тождество, $R_n \equiv 0$; коэффициенты $c_k = P^{(k)}(x_0)/k!$ единственны.
2. **Для $(n+1)$-кратно дифференцируемой функции** формула Тейлора — точное равенство «функция = многочлен + остаток».
3. **Форма остатка выбирается под задачу:** Пеано — для пределов; Лагранж — для численных оценок; Коши и интегральная — для доказательств и специальных исследований.
4. **Из гладкости не следует аналитичность** — нужна сходимость остатка к нулю.
