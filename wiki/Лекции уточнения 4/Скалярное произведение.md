#  Скалярное произведение

$$\vec a\cdot\vec b=|\vec a||\vec b|\cos\varphi=a_xb_x+a_yb_y+a_zb_z$$

```
        b
       /
      / φ
     /______ a
   проекция a на b = |a|cosφ
```

**Свойства:** коммутативно, дистрибутивно, $\vec a\cdot\vec a=|\vec a|^2$.

**Применение:**
- Угол: $\cos\varphi=\dfrac{\vec a\cdot\vec b}{|\vec a||\vec b|}$
- Перпендикулярность: $\vec a\cdot\vec b=0$
- Проекция: $\text{пр}_{\vec b}\vec a=\dfrac{\vec a\cdot\vec b}{|\vec b|}$
