#  Смешанное произведение

$$(\vec a,\vec b,\vec c)=\vec a\cdot(\vec b\times\vec c)=\begin{vmatrix}a_x&a_y&a_z\\b_x&b_y&b_z\\c_x&c_y&c_z\end{vmatrix}$$

```
      c
     /|\
    / | \
   /  |  \  объём параллелепипеда = |(a,b,c)|
  a---+---b
```

**Свойства:** циклическая перестановка не меняет результат; перестановка двух векторов меняет знак.

**Применение:**
- Объём тетраэдра: $V=\tfrac16|(\vec a,\vec b,\vec c)|$
- Компланарность: $(\vec a,\vec b,\vec c)=0$
