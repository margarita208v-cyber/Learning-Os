# Линейные функции матриц

## 1. Определение линейной функции
Функция $f: M_n \rightarrow \mathbb{R}$ называется **линейной**, если выполняются два условия:
1. **Аддитивность**: $f(A+B) = f(A) + f(B)$.
2. **Однородность**: $f(\lambda A) = \lambda f(A)$.

**Матричная запись**: $f(A) = \sum_{i,j} c_{ij} a_{ij} = \text{tr}(C^T A)$, где $C$ — матрица коэффициентов.

### Примеры
- **След матрицы**: $\text{tr}(A) = \sum a_{ii}$ — линейная функция.
- **Сумма всех элементов**: $\sum a_{ij}$ — линейная функция.
- **Определитель**: $\det A$ — **не** линейная функция.

## 2. Полилинейность определителя
Определитель является линейной функцией по каждой строке (столбцу) в отдельности:
$$\det(\dots, \alpha u + \beta v, \dots) = \alpha \det(\dots, u, \dots) + \beta \det(\dots, v, \dots)$$

## 3. Матричные функции (многочлены)
Если $f(x) = \sum c_k x^k$, то $f(A) = \sum c_k A^k$.

### Экспонента матрицы $e^A$
$$e^A = \sum_{k=0}^{\infty} \frac{A^k}{k!} = E + A + \frac{A^2}{2!} + \dots$$
**Свойства**:
- $e^{A+B} = e^A e^B$, если $AB = BA$.
- $\det(e^A) = e^{\text{tr}(A)}$.
- $\frac{d}{dt} e^{tA} = A e^{tA}$.
