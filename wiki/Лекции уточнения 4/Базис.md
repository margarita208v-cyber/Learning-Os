# Конспект 5. Базис

**Базис** — упорядоченная система линейно независимых векторов; любой вектор выражается единственным образом.

- В $\mathbb R^3$: три некомпланарных $\vec e_1,\vec e_2,\vec e_3$; $\vec a=x\vec e_1+y\vec e_2+z\vec e_3$.
- **Ортонормированный** $\vec i,\vec j,\vec k$ — единичные, взаимно перпендикулярные.

```
      z (k)
      |
      |____ y (j)
     /
    x (i)
```

Координаты вектора в ортонормированном базисе — его проекции на оси.
