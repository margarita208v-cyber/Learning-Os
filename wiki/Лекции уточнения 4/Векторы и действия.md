# Векторы и действия над ними

**Вектор** — направленный отрезок, характеризуется модулем $|\vec a|$ и направлением.

```
Сложение (треугольник):        Сложение (параллелограмм):
      B                              B _______ C
     / \                             /|        /|
    /   \                           / |       / |
   A-----C                         A--+------D  |
  AB + BC = AC                    |  |      |  |
                                  |  +------+-+
                                  A'--------B'
```

**Линейные операции:**
- Сложение: $\vec a+\vec b=(a_x+b_x,\ a_y+b_y,\ a_z+b_z)$
- Вычитание: $\vec a-\vec b=\vec a+(-\vec b)$
- Умножение на скаляр: $\lambda\vec a=(\lambda a_x,\lambda a_y,\lambda a_z)$

**Свойства:** коммутативность, ассоциативность, дистрибутивность, наличие нулевого вектора.
