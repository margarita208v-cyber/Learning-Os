# Кинематика: Полный разбор

## 1. Базовые понятия и модели
**Кинематика** описывает геометрию движения.

- **Материальная точка**: Идеализация тела. Применяется, когда размеры тела малы по сравнению с пройденным расстоянием.
- **Система отсчета (СО)**: $\text{Тело отсчета} + \text{Оси координат} + \text{Часы}$.
- **Траектория**: Линия, по которой движется тело.
- **Путь $S$ vs Перемещение $\vec{S}$**:
    - *Путь* — скаляр, сумма всех отрезков траектории. $S \ge |\vec{S}|$.
    - *Перемещение* — вектор $\vec{S} = \vec{r}_{\text{кон}} - \vec{r}_{\text{нач}}$.

---

## 2. Равномерное прямолинейное движение (РПД)
Движение с постоянной скоростью $\vec{v} = \text{const}$.
- **Скорость**: $\vec{v} = \frac{\Delta \vec{S}}{\Delta t}$.
- **Уравнение координаты**: $x(t) = x_0 + v_x t$.
- **График**: Линейная функция. Угол наклона графика $x(t)$ определяет скорость.

---

## 3. Равноускоренное движение (РУД)
Движение с постоянным ускорением $\vec{a} = \text{const}$.

**Основные формулы**:
1. **Скорость**: $v = v_0 + at$.
2. **Координата**: $x = x_0 + v_0 t + \frac{at^2}{2}$.
3. **Путь (перемещение)**: $S = v_0 t + \frac{at^2}{2}$.
4. **Формула без времени**: $v^2 - v_0^2 = 2aS$.

**Пример**: Тело начинает движение из состояния покоя ($v_0=0$) с $a=2\text{ м/с}^2$. Через $t=3\text{ с}$ его скорость $v = 0 + 2 \cdot 3 = 6\text{ м/с}$, а путь $S = 0 + \frac{2 \cdot 3^2}{2} = 9\text{ м}$.

---

## 4. Движение по окружности
- **Период $T$**: Время одного оборота. $\nu = \frac{1}{T}$ — частота.
- **Скорости**:
    - Линейная: $v = \frac{2\pi R}{T} = \omega R$.
    - Угловая: $\omega = \frac{\Delta \phi}{\Delta t} = \frac{2\pi}{T}$.
- **Центростремительное ускорение $a_{цс}$**:
  $$a_{цс} = \frac{v^2}{R} = \omega^2 R$$
  Оно не меняет модуль скорости, а только её **направление**.

- **Тангенциальное ускорение $a_{\tau}$**: Появляется, если модуль скорости меняется: $a_{\tau} = \frac{dv}{dt}$.
- **Полное ускорение**: $\vec{a} = \vec{a}_{цс} + \vec{a}_{\tau}$.
