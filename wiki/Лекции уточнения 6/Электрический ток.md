# Электрический ток

## 1. Основные характеристики

**Сила тока** — скалярная величина, равная заряду, переносимому через поперечное сечение проводника в единицу времени:
$$I = \frac{dq}{dt}.$$
Единица измерения — ампер (А).

**Плотность тока** — векторная величина, характеризующая распределение тока по сечению:
$$j = \frac{I}{S},$$
где $S$ — площадь поперечного сечения.

**Направление тока** — за направление тока принимают направление движения положительных зарядов (противоположно движению электронов).

## 2. Закон Ома

### Для участка цепи (интегральная форма)
$$I = \frac{U}{R},$$
где $U$ — напряжение на участке, $R$ — сопротивление.

### Для участка цепи (дифференциальная форма)
$$\vec j = \sigma \vec E,$$
где $\sigma$ — удельная электропроводность, $\vec E$ — напряжённость электрического поля.

### Сопротивление проводника
$$R = \rho \frac{l}{S},$$
где $\rho$ — удельное сопротивление, $l$ — длина, $S$ — площадь сечения.

### Зависимость сопротивления от температуры
$$R = R_0(1 + \alpha \Delta t).$$

## 3. Работа и мощность тока

**Работа тока:**
$$A = U q = U I t = I^2 R t = \frac{U^2}{R}t.$$

**Мощность тока:**
$$P = \frac{A}{t} = U I = I^2 R = \frac{U^2}{R}.$$

## 4. Последовательное и параллельное соединение

| Соединение | Последовательное | Параллельное |
|---|---|---|
| Сила тока | $I = I_1 = I_2$ | $I = I_1 + I_2$ |
| Напряжение | $U = U_1 + U_2$ | $U = U_1 = U_2$ |
| Сопротивление | $R = R_1 + R_2$ | $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$ |

## 5. Источники тока. ЭДС

**Электродвижущая сила (ЭДС)** — работа сторонних сил по перемещению единичного положительного заряда:
$$\varepsilon = \frac{A_{\text{стор}}}{q}.$$

**Закон Ома для полной цепи:**
$$I = \frac{\varepsilon}{R + r},$$
где $r$ — внутреннее сопротивление источника.

---

## Итог
- Сила тока $I = dq/dt$, плотность тока $j = I/S$.
- Закон Ома: интегральный $U = IR$ и дифференциальный $\vec j = \sigma \vec E$.
- Мощность: $P = UI = I^2 R = U^2/R$.
- ЭДС и закон Ома для полной цепи с учётом внутреннего сопротивления.
