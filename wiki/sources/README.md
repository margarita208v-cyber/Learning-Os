# Карточки источников

Здесь лежат только метаданные и краткая аннотация источника; сам разрешённый файл лежит в `raw/`, а для внешнего материала указывается URL. Используйте [шаблон источника](../../templates/source.md). Карточка не означает, что все утверждения из источника верны: она позволяет их отследить.
