# LLM: воспроизводимое использование ИИ

- `prompts/` — стабильные роли и инструкции; меняйте их через Git.
- `queries/` — конкретные запросы: контекст, модель, дата, результат и проверка.
- `outputs/` — большие или временные ответы. По умолчанию игнорируются Git; добавляйте только ценные, безопасные и проверенные артефакты.
- `evaluations/` — рубрики, тестовые вопросы и оценка качества ответа.

Никогда не отправляйте модели весь репозиторий без необходимости. Передавайте минимальный разрешённый контекст, называйте файлы и просите цитировать только этот контекст.
