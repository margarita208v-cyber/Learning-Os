# Curated LLM outputs

Эта папка по умолчанию игнорируется Git, чтобы не превращать репозиторий в архив чатов. Если ответ действительно нужен как учебный артефакт, перенесите его в соответствующую заметку своими словами или снимите игнорирование для одного безопасного файла и добавьте provenance/проверку.
