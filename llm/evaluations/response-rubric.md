# Рубрика проверки ответа LLM

| Критерий | 0 — плохо | 1 — частично | 2 — хорошо |
| --- | --- | --- | --- |
| Grounding | нет связи с контекстом | часть утверждений связана | все ключевые утверждения привязаны к разрешённым источникам |
| Factuality | есть выдумки/ошибки | есть сомнительные места | проверено человеком или явно помечено |
| Pedagogy | даёт готовый ответ | объясняет, но мало проверяет | помогает думать, задаёт вопросы, не заменяет работу |
| Provenance | нет указателей | есть общая ссылка | точный файл и раздел/страница |
| Safety/ethics | есть риск данных/обмана | риск неясен | правила курса, права и данные учтены |

Ответ с нулём по factuality или safety не используйте как основание для wiki или сдаваемой работы.
